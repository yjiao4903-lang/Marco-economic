# Task — V3 Local Dashboard（Streamlit）（Window H）

> 状态：**已补全（协调员，2026-08-30）**。V2.6 交付后开窗。
> 素材来源：02_ARCHITECTURE §13（UI Layer）、00_MASTER_SPEC §13（可追溯性）、
> §14（明确后置：不做 FastAPI/React/Next.js）、README 既有报告入口。

## 窗口范围

只做 **本地可视化 Dashboard（Streamlit）**：把已产出的宏观快照、市场确认、
资产指引、结构风险诊断统一展示，保持全链路可追溯。
**不做**：Cloud（V4）、多用户、鉴权、自动交易、交易按钮、仓位建议、
Web 前端框架（React/Next.js/FastAPI）。

**硬约束（02_ARCHITECTURE §13）**：UI 层使用 **Streamlit**；不建立 FastAPI / React / Next.js。

## 前置条件

1. **V2.6 PASS**（S1/S2/S3 结构风险可展示，tag `v0.7-structural-risk`）；
2. 四个报告入口可用：`macro_report.py` / `market_report.py` / `asset_report.py` /
   `structural_report.py`（各自产出可追溯快照 CSV 到 data/local/）。

## 展示内容（全部只读，不新增计算逻辑）

- **宏观总览**：Regime + 四因子（score/breadth/confidence）+ 15 Core 信号表
  （status/provenance/score/level/momentum/freshness/coverage/breakdown/missing）；
- **市场确认**：Market Data Matrix + 六信号 1M/3M/6M/percentile + Divergence 五状态；
- **资产指引**：7 资产 Score/View/1M/3M/Factor contribution/Signal contribution/
  Market confirmation/Confidence；
- **结构风险**：S1/S2/S3 诊断状态与最新值（明确标注"不进入资产评分"）；
- **可追溯下钻**：Asset → Factor → Signal → Raw Series → Provider（00_MASTER_SPEC §13
  硬要求）；点击/筛选可下钻到原始序列与来源。

## 技术要求

- 只读 canonical / data/local 快照，**不得**在 UI 层重新计算信号或触发更新；
- as-of 对齐：所有面板同一天快照（延续各 report 的 --today 语义）；
- synthetic 永不显示为真实数据（沿用 production 隔离）；
- 无任何 BUY/SELL/仓位字样（延续红线）。

## Acceptance Criteria

1. Streamlit 应用可本地启动，四个面板完整展示；
2. 每面板只读快照，不触发 update_sources / 不重新计算（源码检查）；
3. 资产可下钻到 Signal→Raw Series→Provider 全链路；
4. as-of 同天对齐；synthetic 不显示为真实；
5. 无买卖/仓位字样；无鉴权/多用户/云功能；
6. 完整 pytest PASS（V2.6 基线 + 新增，若 UI 逻辑有可测部分）；
7. V1–V2.6 frozen components 未被重写。
